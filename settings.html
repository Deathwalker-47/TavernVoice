Voice director (bridge helper LLM)

The helper only inserts tags; if it changes any words, the sentence is spoken exactly as written. Needs the Flux LoRA Bridge with a helper LLM key (NanoGPT).
Later sentences are tagged while earlier ones play, so only the first one can delay the voice. The default, GLM 5.3 Flash Uncensored, usually answers in about 1.2 s and doesn't filter adult lines.
